## 바뀐 것

- **데스크톱 앱이 새로 만들어졌습니다(Electron).** 화면은 그대로이고, 앱 안의 Node 서버가 보드와 세션을 맡습니다. tmux 없이 세션이 돌고, 앱을 닫아도 세션은 남았다가 다시 열면 이어집니다. 컴퓨터를 다시 켠 뒤에도 열려 있던 세션이 대화째 다시 열립니다.
- **세 OS 설치 파일**: macOS(Apple Silicon `mac-arm64.dmg`, Intel `mac-x64.dmg`) · Windows(`win-x64.exe`, WSL 필요 없음 — 사용자 범위 설치) · Linux(`linux-x86_64.AppImage`). 서명하지 않은 앱이라 처음 한 번 경고를 넘깁니다([README](https://github.com/calmonion7/Anvil#설치)).
- **처음 열 때 준비물 자동 설치**: claude CLI·forge 플러그인(Windows는 Git for Windows까지)을 「준비 중」 화면에서 알아서 설치한 뒤 보드로 넘어갑니다.
- **앱 안 업데이트**: 다음 버전부터는 보드 위 띠의 [업데이트] 한 번으로 바뀝니다. 앱이 새 버전으로 다시 열리고 세션은 대화째 이어집니다. 작업 중인 세션이 있으면 끝난 뒤 바뀝니다.
- **[프로젝트 추가]**: 세 OS 모두 OS 기본 폴더 창으로 고릅니다.

## 0.1.x(Tauri)에서 옮겨 오는 분

0.1.x 앱은 이 버전으로 자동 업데이트되지 않습니다. 아래 순서로 한 번만 정리한 뒤 새 설치 파일을 설치하세요.

1. 옛 앱에 남은 세션 끄기(터미널): `tmux -L anvil kill-server`
2. 옛 앱(`/Applications/Anvil.app`)을 휴지통으로 — Windows는 WSL 안의 옛 설치도 더 쓰지 않습니다.
3. 새 설치 파일을 설치하고 열면, 등록했던 프로젝트를 다시 [프로젝트 추가]로 등록합니다.

다운로드 · 준비물 · 사용법은 [README](https://github.com/calmonion7/Anvil#readme)를 참고하세요.
