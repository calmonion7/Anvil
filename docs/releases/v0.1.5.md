## 고친 것

깨끗한 맥에서 v0.1.4를 처음 설치해 보며 찾은 문제입니다.

- **node가 없어 forge 훅이 오류를 내던 문제**: 깨끗한 맥에는 node가 없어 forge의 세션 시작·종료 훅이 실패했습니다. 이제 준비물에 node가 들어갑니다. macOS [설치]는 nodejs.org 공식 압축본(v22 LTS)을 받아 체크섬을 검증한 뒤 `~/.local/bin`에 넣습니다 — 관리자 암호나 설치 창이 필요 없습니다. Windows(WSL)·Linux는 띠에 표시만 하니 직접 설치하세요.
- **개발자 도구 설치 창이 Anvil 뒤로 숨던 문제**: [설치]가 띄운 설치 창을 맨 앞으로 가져옵니다.
- **[세션 열기] 뒤 바로 타이핑이 안 되던 문제**: 세션을 열면 터미널에 바로 초점이 가서, 첫 실행 때 뜨는 신뢰 질문에 곧장 답할 수 있습니다.

다운로드 · 준비물 · 사용법은 [README](https://github.com/calmonion7/Anvil#readme)를 참고하세요.
