Anvil의 첫 릴리스입니다. forge(Claude Code 플러그인)로 진행하는 프로젝트들의 진행 상황을 한 화면의 보드로 보고, 단계마다 Claude Code 세션을 띄워 이어 가는 데스크톱 앱입니다.

## 주요 기능

- **forge 보드** — 등록한 프로젝트의 `.forge/` 를 읽어 백로그 · 실행 · 회고 · 완료를 보드로 보여 줍니다(읽기만 합니다). 「지금」 띠와 건수 칩, 목록 · 문서 팝업.
- **역할별 세션** — 계획 · 실행 `claude` 세션을 tmux 안에 띄웁니다. 앱을 껐다 켜도 세션이 그대로 이어집니다. 세션 이름 · 모델 · effort 표시.
- **흐름도** — forge 정보 흐름을 실시간 애니메이션으로 표시.
- **알림** — 세션이 입력을 기다리면 알림(Windows는 앱이 꺼져 있어도 토스트).
- **준비물 자동 설치** — tmux · Claude Code CLI · forge 플러그인이 없으면 안내 띠가 뜨고, macOS에서는 [설치] 한 번으로 설치. forge 플러그인 업데이트 알림.
- **설정** — 계획 · 실행 세션 모델 선택(기본 opus · sonnet), 화면 언어(자동 · 한국어 · English).
- **자동 업데이트** — 새 버전이 나오면 앱 상단 띠의 [업데이트·재시작]으로 갱신.
- 창 크기 · 위치 기억(전체화면 종료 후에도 복원).

## 다운로드

| OS | 파일 |
|---|---|
| macOS (Apple Silicon) | `Anvil_0.1.0_aarch64.dmg` |
| macOS (Intel) | `Anvil_0.1.0_x64.dmg` |
| Windows (실험용) | `Anvil_0.1.0_x64-setup.exe` 또는 `.msi` |
| Linux (실험용) | `.AppImage` · `.deb` · `.rpm` |

## 알아둘 것

- **macOS**: Apple 서명이 없는 앱입니다. 처음 열 때 막히면 Finder에서 우클릭 → 열기. "손상되었습니다"가 나오면 `xattr -cr /Applications/Anvil.app`.
- **Windows**: 세션은 WSL 안에서 돕니다. WSL(Ubuntu)에 tmux · claude CLI · forge를 직접 설치해야 합니다([설치] 버튼은 macOS 전용).
- **Linux**: tmux · claude CLI · forge를 직접 설치합니다.
- 세션마다 claude가 돌아 Claude 요금제 사용량이 나갑니다.

자세한 준비물 · 사용법은 [README](https://github.com/calmonion7/Anvil#readme), 문제는 [Issues](https://github.com/calmonion7/Anvil/issues)에 남겨 주세요.
