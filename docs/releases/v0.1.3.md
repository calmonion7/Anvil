## 고친 것

깨끗한 맥에서 v0.1.2를 처음 설치해 보며 찾은 문제입니다.

- **forge 플러그인 설치가 실패하던 문제**: 깨끗한 맥에는 git(명령어 라인 개발자 도구)이 없어 forge를 받지 못했고, 띠에는 엉뚱한 오류("not found in marketplace")만 보였습니다. 이제 개발자 도구가 준비물로 표시되고, [설치]가 macOS 기본 설치 창을 띄웁니다. 창에서 설치를 마친 뒤 [다시 확인] → [설치]를 누르면 forge까지 설치됩니다. 실패하면 진짜 원인이 띠에 보입니다.
- **[로그인]으로 연 터미널에서 `claude`를 찾지 못하던 문제**: claude 공식 설치 위치(`~/.local/bin`)를 경로에 넣고 실행합니다.

다운로드 · 준비물 · 사용법은 [README](https://github.com/calmonion7/Anvil#readme)를 참고하세요.
