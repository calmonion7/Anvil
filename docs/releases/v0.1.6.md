## 새로 된 것

- **Windows(WSL)·Linux에서도 [설치] 한 번으로 준비물 설치**: macOS처럼 띠의 [설치]가 빠진 node·claude CLI·forge를 관리자 암호 없이 항목별로 넣습니다. Windows는 WSL 안에 설치합니다. curl이 없는 데스크톱 Ubuntu에서는 wget으로 받습니다.
- **tmux를 세 OS 모두 앱에 내장**: Linux·Windows도 macOS처럼 앱에 든 tmux 3.6a를 쓰므로 tmux를 따로 깔 필요가 없습니다. Windows는 WSL의 `~/.local/share/anvil/bin/tmux-3.6a`에 한 번 복사해 씁니다.
- **node는 22 이상**: 더 낮은 node는 없는 것으로 칩니다. 사용자에게 옛 node가 있으면 그 node는 그대로 두고, Anvil 전용 폴더(`~/.local/share/anvil/node`)에 v22를 받아 Anvil 세션에서만 씁니다.
- **Windows 안내가 정확해짐**: WSL이 없을 때(`wsl --install`)와 배포판이 없을 때(`wsl --install -d Ubuntu`)를 구분해 안내하고, 그 뒤로는 macOS·Linux처럼 빠진 항목 목록과 [설치]를 보여 줍니다.
- **Linux·Windows의 git**: forge 플러그인을 받는 데 git이 필요합니다. git 설치에는 관리자 암호가 필요해 띠가 `sudo apt install git`을 안내합니다.
- **Linux·Windows 로그인**: claude를 설치하면 'Anvil에서 세션을 열면 claude가 로그인을 안내합니다'가 뜹니다(외부 터미널 창을 열지 않습니다).

## 알아둘 것

- **이미 시스템 tmux로 Anvil 세션을 쓰던 Linux·WSL 사용자**: 업데이트 뒤에는 앱에 든 tmux 3.6a로 세션을 엽니다. 열려 있던 세션은 앱을 다시 시작한 뒤 한 번 닫고 다시 여세요(tmux 버전이 다르면 이어 붙지 않을 수 있습니다).
- Linux 배포본은 x86_64만 있습니다.
