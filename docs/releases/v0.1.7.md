## 고친 것

- **[설치] 뒤 띠가 이미 설치된 준비물을 '필요'로 보이던 문제**: Windows(WSL)에서는 준비물 확인 한 번에 수십 초가 걸리는데, 그동안 띠가 설치 전의 '필요: …' 문구를 그대로 보여 [설치]가 안 된 것처럼 보였습니다. 이제 확인이 도는 동안에는 띠에 '확인 중…'이 보이고 [다시 확인]·[설치] 버튼이 잠시 꺼집니다. [다시 확인]을 눌렀을 때도 같습니다.
- 확인이 겹쳐 돌 때 먼저 시작한 확인의 응답이 늦게 와도 더 새 결과를 덮지 않습니다.

다운로드 · 준비물 · 사용법은 [README](https://github.com/calmonion7/Anvil#readme)를 참고하세요.
