# Anvil

forge 워크플로우를 쓰는 여러 프로젝트의 `.forge/` 상태를 한 화면에서 보고, 그 프로젝트에서 forge를 실행하는 가벼운 데스크톱 앱.

## Language

**세션**:
Anvil이 한 프로젝트에서 띄운 대화형 claude 터미널 하나. Anvil 밖(iTerm 등)에서 띄운 claude는 세션이 아니다.
_Avoid_: 작업, 터미널(단독으로 쓸 때)

**계획 세션**:
프로젝트마다 하나뿐인, 계획을 쌓는(fg-ask) 역할의 세션. 계획은 여러 개를 계속 쌓을 수 있다.

**실행 세션**:
프로젝트마다 하나뿐인, 계획을 실행하는(fg-run·fg-next) 역할의 세션. forge의 활성 작업 자리가 하나라 실행은 한 번에 하나뿐이다.

**세션 상태**:
세션이 지금 어떤 처지인지. 작업 중(claude가 응답을 만드는 중), 입력 대기(사람의 입력을 기다리는 중), 종료 셋 중 하나이다. 입력 대기가 끼어들어도 된다는 뜻은 아니다. 대화 중간의 질문도 입력 대기다.

**프로젝트**:
사용자가 Anvil에 직접 등록한 폴더 하나. `.forge/`가 아직 없어도 프로젝트가 될 수 있다.
_Avoid_: 레포, 워크스페이스

**진행 영역**:
한 프로젝트에서 forge가 다음에 집어갈 것들(활성 작업, 백로그). 항상 현재 브랜치의 forge root에서만 읽는다.

**기록 영역**:
한 프로젝트에서 이미 끝난 것들(완료 작업, 회고, 후속후보). 최상위 `.forge/` 위에 현재 브랜치 root를 겹쳐 하나의 이력으로 본다.
_Avoid_: 히스토리(단독으로 쓸 때)

**후속후보**:
끝난 작업의 회고나 실행 기록에 "다음에 해볼 것"으로 남은 한 줄 항목. 아직 작업(task)이 되지 않은 아이디어이다.
_Avoid_: 후속 작업, 다음 탐구, 후속 큐
