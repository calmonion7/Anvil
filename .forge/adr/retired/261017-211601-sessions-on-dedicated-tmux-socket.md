# 세션은 Anvil 전용 tmux 소켓 위에서 돌고, 상태는 claude 훅이 파일로 남긴다

세션(Anvil이 띄운 claude 터미널)은 앱을 닫아도 살아남아야 한다. 실행 세션의 fg-run은 수십 분씩 걸리기 때문이다. 앱이 claude를 자식 프로세스로 직접 띄우면 앱 종료가 곧 실행 중단이 되므로, 세션을 전용 소켓(`tmux -L anvil`)의 tmux 세션으로 띄우고 앱의 터미널 패널은 거기에 붙기만 한다. 사용자의 평소 tmux와는 소켓이 달라 섞이지 않는다. 앱이 꺼져 있는 동안에도 상태를 잃지 않도록, 세션 상태(작업 중·입력 대기·종료)와 세션 ID는 앱이 아니라 claude 훅(`--settings`로 주입)이 파일에 기록한다. 입력 대기 알림은 앱이 떠 있으면 앱이, 꺼져 있으면 훅이 띄운다.

## Considered Options
- 앱과 함께 종료 + 닫기 전 경고 + `claude --continue`로 이어 붙이기 — 가장 단순하지만, 실행 중이던 fg-run이 끊긴다.
- 창만 닫고 메뉴바 상주 — 앱이 죽거나 Cmd+Q를 누르면 같은 문제가 생긴다.
