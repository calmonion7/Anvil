# Anvil은 `.forge/`를 직접 읽기만 하고, 절대 쓰지 않는다

forge 상태는 fg-* 스킬이 정해진 규칙(봉인 게이트, 작업 번호, 브랜치 root)으로 쓰는 파일이라, 다른 도구가 고치면 상태가 어긋난다. 그래서 Anvil이 forge를 바꾸는 길은 하나뿐이다. 세션의 claude 입력창에 `/forge:fg-*` 명령을 채워 넣고 사람이 Enter를 누르는 것이다. 앱만의 표시 상태(후속후보 숨김, 등록한 프로젝트 목록)는 앱 데이터 폴더에 둔다. 읽기는 `forge-status` 출력에 기대지 않고 파일을 직접 파싱한다. `forge-status`에는 기계가 읽을 수 있는 출력이 없고, 활성 작업과 최근 완료 다섯 건만 보여 주기 때문이다. 대신 forge 규칙(브랜치 root 해석, STATUS 필드, 단계 판정)을 Anvil 안에 다시 구현한다. forge가 `--json` 출력이나 후속후보 전용 파일을 내놓으면 그쪽으로 옮긴다.
