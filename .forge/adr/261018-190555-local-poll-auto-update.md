# 자동 업데이트는 이 Mac의 launchd 폴링과 로컬 빌드로 하고, 새 버전은 다음 실행 때 반영한다

main에 머지되면 사람이 손대지 않아도 설치본이 따라와야 한다. 이 Mac의 launchd 에이전트가 5분마다 `git ls-remote`로 main SHA만 비교하고, 바뀌었을 때만 전용 빌드 클론에서 pull·빌드한다. 빌드가 성공하면 실행 중인 앱을 끄지 않고 `/Applications/Anvil.app` 번들만 바꾼다. 앱은 디스크의 번들이 자기와 다른 커밋임을 알아채 "새 버전 준비됨 · 재시작" 띠를 띄운다. task 7에서 정한 "사람이 직접 실행, 자동 훅 없음"을 대체한다.

## 고려한 대안
- **Tauri updater + GitHub Actions + Releases**: 레포가 비공개라 릴리스를 받으려면 앱에 GitHub 토큰이 있어야 하고, macOS 러너 분이 10배로 계산되며, 업데이트 서명 키를 관리해야 한다. 사용자는 이 Mac 하나뿐이라 얻는 것이 없다. 사용자가 여러 대가 되면 다시 본다.
- **self-hosted 러너**: 러너도 내부적으로 GitHub을 폴링하고, 러너 등록·격리 부담이 더해진다.
- **로컬 ref 감시(WatchPaths)**: 폴링은 없지만 누군가 로컬에서 pull해야 촉발되어 웹 머지만으로는 동작하지 않는다.
- **빌드 즉시 앱 재시작**: 쓰던 창이 갑자기 꺼진다. 세션은 tmux라 안전하지만 흐름이 끊긴다.
