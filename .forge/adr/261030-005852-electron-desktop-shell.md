# Anvil은 Electron 설치 앱으로 배포하고, 서버는 앱과 떨어져 돌며 재부팅 뒤 세션을 복구한다

ADR 261029-121641은 백엔드를 Node 서버로 옮기면서 창을 브라우저 탭(원하면 PWA)으로 두었다. 1/4을 마치고 써 보니 사용자가 원한 것은 "설치 파일을 받아 여는 데스크톱 앱"이었고, 탭이나 PWA는 거기에 미치지 못했다. 그래서 Node 서버·node-pty 세션·세 OS 한 코드 경로라는 261029의 핵심은 유지하고, **창과 배포 형태만** 바꾼다.

## 결정

- **껍데기 = Electron.** 세 OS가 같은 Chromium으로 그리므로 브라우저 Playwright로 검증한 화면이 그대로 출시되고, Playwright가 Electron 앱을 직접 띄워 세 OS(mac 포함) e2e를 같은 방식으로 돌린다. 서버는 Electron 안의 Node로 돈다(`ELECTRON_RUN_AS_NODE`) — **node는 준비물에서 빠진다.** forge 훅용으로는 세션 PATH에 Electron을 node로 부르는 대체 실행 파일을 둔다.
- **서버는 앱과 떨어진 프로세스다.** 앱은 열릴 때 서버가 없으면 띄우고 붙는다. 앱을 꺼도 서버와 세션은 산다(ADR 261017-211601의 요구 — fg-run은 수십 분 걸린다). 살아 있는 세션도 붙은 창도 없이 5분이 지나면 서버가 스스로 내려간다. 로그인 자동 시작 서비스는 두지 않는다.
- **재부팅·서버 재시작 뒤 세션을 대화째 복구한다.** 서버는 열려 있던 세션(프로젝트·역할·claude 대화 ID)을 기록해 두고, 다시 뜰 때 `claude --resume <ID>`로 띄운다. 복구는 앱을 열 때 일어난다. 끊긴 동작을 자동으로 이어 치지는 않는다(사람이 확인한다).
- **설치 파일로 배포하고 서명하지 않는다.** 대상은 주변 사람들이다. mac `.dmg`(arm64·x64), Windows 사용자 범위 설치 프로그램 `.exe`(x64), Linux `AppImage`(x64). 처음 한 번 OS 경고를 넘기는 것은 안내로 해결한다.
- **준비물(claude CLI·forge, Windows는 Git)은 첫 실행 때 앱이 자동으로 설치한다.** 로그인은 첫 세션 안에서 claude가 받는다.
- **업데이트는 세 OS 공통 자체 업데이터다.** 확인·내려받기·체크섬 검증·"작업 중인 세션이 없을 때만"·재시작 뒤 세션 복구는 공통이고, 교체 동작만 OS별이다(mac `.app` 교체, Windows 설치 프로그램 조용히 실행, Linux AppImage 교체). 서명이 없으면 macOS에서 electron-updater가 동작하지 않으므로 쓰지 않는다.

## 고려한 대안

- **브라우저 탭 + PWA(261029 그대로)**: 비용이 가장 적지만 설치 파일이 아니다 — 사용자가 원한 형태가 아니었다.
- **Tauri 얇은 껍데기 + node 동봉**: 가볍고 기존 빌드·업데이터 파이프라인을 살리지만, 화면 엔진이 OS마다 달라(WKWebView·WebView2·WebKitGTK) 한글 입력·e2e를 엔진별로 맞춰야 한다. "OS 상관없이 편한 개발"이라는 기준에서 졌다. 대가로 메모리와 설치 파일 크기를 내준다.
- **서버를 앱 안에서 돌리기**: 가장 단순하지만 앱 종료가 곧 실행 중단이다(261017-211601이 기각한 것).
- **Apple 서명($99/년)**: 경고 없이 열리고 electron-updater를 쓸 수 있지만, 주변 사람만 쓰는 지금은 비용 대비 이득이 작다. 사용자가 늘면 다시 본다.

## 결과

- 261029-121641의 "창은 브라우저 탭, 원하면 PWA", "한 줄 설치 스크립트", "Releases tarball + `npm i -g`", "로그인 자동 시작"을 이 ADR이 대체한다. Node 서버·node-pty·tmux 없음·토큰과 Origin 검사는 그대로 유효하다.
- 브라우저로 여는 길(`?token=` 주소)은 개발과 화면 e2e용으로 남는다.
- 작업은 `electron-app-1of6`~`6of6`로 나눈다. 대체된 Tauri 계열 ADR은 6/6에서 은퇴시킨다.
