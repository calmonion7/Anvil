# 보드를 「지금」 띠 중심으로 줄이고 목록·문서는 팝업으로, 앱 창 크기·위치를 기억한다

## 목표
목록이 터미널 영역을 잡아먹지 않게 한다. 위쪽은 내용 높이만큼의 고정 띠로 줄이고, 후속후보·최근 완료·백로그는 건수 칩으로만 보인다. 칩을 누르면 팝업으로 목록을 열어 지금과 같은 액션을 쓴다. 앱 창 크기·위치·최대화는 다음 실행 때 복원한다.
출처: #4 role-columns-and-session-names 실행 기록의 후속후보 두 건 (UAT (a)(b)(c) 의견)

## 근거 (source of truth)
- 용어: `.forge/CONTEXT.md` — 진행 영역, 기록 영역, 후속후보, 계획 세션, 실행 세션
- ADR `261017-211602-anvil-never-writes-forge` — 창 상태·표시 상태는 앱 데이터에만 둔다(`.forge/` 쓰기 없음)

## 결정 (fg-ask 2026-10-18)
1. 위쪽 = 고정 높이 띠: 「지금」 띠 + 루프 줄(있을 때) + 건수 칩 3개(후속후보 · 최근 완료 · 백로그). 가로 경계(`hsplit`)와 `listRatio` 저장은 없앤다. 세로 경계(두 열 비율 `split`)·프로젝트 영역 접기는 그대로.
2. 문서는 큰 오버레이로 연다(띠 아래 ~ 터미널을 덮음). Esc·×로 닫음. 목록 팝업에서 연 문서는 목록 팝업 위에 겹치고, 닫으면 목록으로 돌아간다.
3. 팝업 목록은 지금 목록 그대로(착수·숨김·되돌리기·숨긴 항목 보기, 전체 기록 보기, 실행). 착수·실행 → 팝업 닫힘. 숨김·되돌리기·문서 열기 → 팝업 유지. 후속후보 칩 숫자는 숨김 제외. 0건 칩도 보이고 누르면 "비어 있음" 안내.
4. 창 기억 = `tauri-plugin-window-state`. 크기·위치·최대화만 복원(macOS 전체화면은 복원 안 함). 기본 1280×820은 첫 실행에만.
5. 「지금」 띠의 회고 대기 표시(활성 작업 없을 때)는 띠에 그대로 둔다.

## 슬라이스

- S2 위쪽 고정 띠 + 건수 칩 — `+page.svelte` 격자를 [띠 / 터미널] 구조로 바꾸고 `hsplit`·`listRatio` 제거, 기존 `anvil.layout`의 `listRatio` 키는 무시. 완료: DoD 2, UAT (b)
- S3 목록 팝업 — `PlanColumn`/`RunColumn`의 목록을 팝업(`role="dialog"`, Esc 닫기, 바깥 클릭 닫기)으로 옮기고 결정 3의 닫힘 규칙 적용. 완료: DoD 3, UAT (c)(d)
- S4 문서 오버레이 — 문서 칸을 오버레이로 옮기고 팝업 위 겹침·복귀. 완료: UAT (e)

1. `grep -q tauri-plugin-window-state src-tauri/Cargo.toml && grep -q tauri_plugin_window_state src-tauri/src/lib.rs` — 사전: 실패(전진 검사)
2. `! grep -qE 'hsplit|listRatio' src/routes/+page.svelte` — 사전: 실패(전진 검사)
3. `grep -lq 'role="dialog"' src/lib/*.svelte src/routes/+page.svelte` — 사전: 실패(전진 검사)
4. `npm run check` → 0 ERRORS — 사전: 통과
   - 회귀 방지 검사라 미리 통과하는 게 맞다
5. `npm run tauri build -- --debug` exit 0 — 사전: 실행 안 함(무거움), #4 봉인 시점 통과
   - 회귀 방지 검사

사람 판정 UAT (판정 상황 → 보여야 할 것):
- (a) 창을 최대화하거나 크기·위치를 바꾼 뒤 앱 종료 → 재실행: 같은 크기·위치(최대화면 최대화)로 뜬다. 전체화면에서 종료하면 재실행 때 전체화면이 아니다.
- (b) 백로그·후속후보가 있는 프로젝트: 위쪽은 띠·칩 한 덩어리 높이뿐이고 그 아래 전부 터미널. 위아래 경계를 끌 수 없다. 칩 숫자가 목록 수와 같다(후속후보는 숨김 제외).
- (c) 후속후보 칩 → 팝업: '숨김' 눌러도 팝업 유지·숫자 감소, '착수' 누르면 팝업 닫히고 계획 세션 입력창에 `/forge:fg-ask` 채워짐. 백로그 칩 → '실행' 누르면 닫히고 실행 세션에 `/forge:fg-run` 채워짐. Esc·바깥 클릭으로 닫힘.
- (d) 0건 칩(예: noforge-test 빈 폴더 프로젝트) → 팝업에 "비어 있음" 안내.
- (e) 팝업 목록에서 문서 열기 → 문서가 위에 겹쳐 열림, Esc 한 번에 문서만 닫히고 목록 팝업으로 복귀. 띠의 plan 버튼으로 연 문서는 닫으면 터미널이 그대로 보인다.
