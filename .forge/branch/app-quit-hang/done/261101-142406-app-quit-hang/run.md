## 계획 밖 변경·판단
- 열기 실패 기록에 까닭(`start`·`activate`·`second-instance`·`token`)과 끄는 중 여부를 남긴다(`open(reason)`). S2에서 원인을 가리려고 넣었고, 다음 재발 때도 쓸모 있어 남겼다.
- 끄는 중 열기가 끊기는 것 자체는 막지 않았다. 창을 닫는 중에 읽기가 끊기는 것은 정상이고, 이제는 기록만 남고 해가 없다.
- `quitApp`의 `app.evaluate(app.quit)`도 30초 제한으로 감쌌다 — 주 프로세스가 붙잡히면 그 호출이 돌아오지 않아 테스트가 실패 대신 멈췄다(예전 코드 빨강 확인 때 필요).
