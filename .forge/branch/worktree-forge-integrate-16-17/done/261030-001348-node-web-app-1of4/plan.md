# Node 서버 + 웹 화면으로 이 Mac에서 기능 동등 (Node 전환 1/4)

## 목표 / 하지 않을 것
- 목표: Tauri(Rust) 백엔드를 Node 서버로 옮겨, 이 Mac에서 브라우저로 지금과 같은 보드·세션·프로젝트 등록·슬래시 채우기를 쓸 수 있게 한다. 세션은 tmux 없이 서버가 node-pty로 쥐고, 브라우저를 닫았다 다시 열어도 이어진다.
- 하지 않을 것: 한 줄 설치·자동 시작·릴리스·[업데이트] 띠(2/4), Windows·Linux 확인(3/4), `src-tauri/` 삭제와 Tauri 의존 제거(4/4), 입력 대기 OS 알림(별도 작업), 기존 Tauri 앱 데이터 이전(새로 시작). **Tauri 쪽은 동결한다.** 고치지 않고, `cargo test`가 계속 통과하는 상태만 지킨다.

## 근거
- 용어: 세션·계획 세션·실행 세션·세션 상태·프로젝트·진행 영역·기록 영역·후속후보·준비물 — `.forge/CONTEXT.md`
- 관련 ADR: `adr/261029-121641-node-local-web-app.md`(이번 전환), `.forge/adr/261017-211602-anvil-never-writes-forge.md`(그대로 유효 — `.forge/`는 읽기만 한다)
- 화면을 바꾸는 S5 전에 `~/.claude/design/UIUX.md`를 읽는다(전역 지침).
- 완료 정의(DoD):
  1. `node --test server/` → 0 실패. S1의 골든 비교 테스트가 포함되어야 한다.
     - 사전 상태(실측): `server/` 없음. 전진 검사다.
  2. `npx playwright test` → 0 실패. 기존 40개 시나리오이며, 가짜 IPC를 새 API 클라이언트용 가짜로 바꾼 상태에서 돈다.
     - 사전 상태: 지금 통과. 회귀 방지다.
  3. `grep -rln "@tauri-apps" src | wc -l` → `0`.
     - 사전 상태(실측): `4`. 전진 검사다.
  4. `npm run check` → 오류 0.
  5. `(cd src-tauri && cargo test)` → 통과. Tauri 동결 상태의 회귀 방지다.
     - 사전 상태: 통과(이번 작업은 `src-tauri/`를 고치지 않는다).
  6. 토큰 없는 요청, 다른 Origin에서 온 요청, `Host`가 localhost가 아닌 요청이 모두 거절된다. S2의 Node 테스트로 확인하며, 1번에 포함된다.
  7. UAT(이 Mac, 사람):
     - 서버를 띄워 브라우저로 연다. 등록한 프로젝트 보드가 보인다.
     - 계획 세션을 열어 claude와 대화한다.
     - 탭을 닫았다 다시 연다. 같은 세션 화면이 이어지고, 탭 제목에 입력 대기 표시가 나온다.
     - 보드의 단계 버튼으로 `/forge:fg-*`가 입력창에 채워진다.

## 작업 조각
- [ ] S1. **동작 고정(pin)**:
  - `src-tauri/tests/forge.rs`의 27개 사례가 쓰는 픽스처(`src-tauri/tests/fixtures/` 5종)마다, Rust 파서의 출력을 JSON 골든 파일로 뽑아 `server/test/golden/`에 커밋한다. 골든 덤프는 Rust 테스트 하나를 추가하는 방식으로 만든다. 이 추가가 동결 예외의 유일한 Rust 변경이다.
  - 같은 픽스처를 읽어 골든과 비교하는 Node 테스트의 뼈대를 만든다(아직 빨강).
  - 완료 기준: 골든 파일이 픽스처 수만큼 있고, `cargo test`가 통과한다.
- [ ] S2. **서버 골격과 보안** (depends: S1):
  - `server/`에 Node 22 서버를 만든다. 내장 http에 웹소켓(`ws`)만 붙이고, 빌드된 SvelteKit 정적 파일을 서빙한다.
  - `127.0.0.1` 고정 포트에만 연다. 포트는 실행 때 정하고, 환경변수로만 바꿀 수 있다.
  - 실행할 때마다 토큰을 만들어 데이터 폴더 파일과 쿠키로 확인하고, Origin·Host를 검사한다.
  - 지금 쓰는 IPC 27개 중 남길 것을 API로 옮긴다. 없앨 것은 `deps_install`·`deps_login`·`updater_*`·`notify`이고, `deps_status`·`forge_plugin_*`는 남긴다.
  - 완료 기준: DoD 6의 거절 테스트 통과.
- [ ] S3. **forge 읽기 이식** (depends: S2):
  - `forge.rs`(670줄)를 옮긴다. 대상은 브랜치 root 해석, 진행·기록 영역, STATUS·단계 판정, 후속후보, 문서 읽기다.
  - 파일 감시로 바뀐 프로젝트를 클라이언트에 밀어 준다. 프로젝트 목록과 설정은 새 데이터 폴더에 둔다.
  - 완료 기준: S1의 골든 비교가 초록.
- [ ] S4. **세션 이식(tmux 없음)** (depends: S2):
  - `session.rs`·`slash.rs`의 동작을 node-pty로 옮긴다. 대상은 역할별 세션 시작·종료·이름·제목·모델, 세션 상태 훅, 상태줄 모델 기록, 입력창 채우기, 슬래시 목록이다.
  - 상태 훅과 상태줄 래퍼는 sh·jq 대신 **Node 스크립트**로 쓴다. 3/4의 Windows가 그대로 쓰게 하기 위해서다.
  - 브라우저 연결이 끊겨도 pty는 서버에 남고, 다시 붙으면 최근 출력을 재생한다.
  - 완료 기준: 세션 상태 전이(작업 중→입력 대기→종료)와 재접속 재생의 Node 테스트가 통과.
- [ ] S5. **화면 연결** (depends: S3, S4):
  - `@tauri-apps/api` 호출을 API·웹소켓 클라이언트 한 곳으로 바꾼다.
  - Tauri 창 기능을 정리한다. 창 위치 기억과 전체화면 복원은 없애고, 팝업 보드는 브라우저 새 창으로 연다.
  - 탭 제목에 입력 대기 표시를 넣는다.
  - 준비물 띠는 빠진 항목과 [다시 확인]만 남긴다. 설치 줄 안내 자리는 2/4에서 채운다.
  - `e2e/mock-ipc.ts`를 새 클라이언트용 가짜로 바꾼다.
  - 완료 기준: DoD 2·3·4.
- [ ] S6. **개발 실행 경로** (depends: S5): `npm run dev`(화면)와 서버를 함께 띄우는 스크립트를 만들고, README 「개발」 절에 한 줄 적는다(Tauri 줄은 4/4에서 지운다). 완료 기준: 깨끗한 클론에서 `npm ci` 뒤 그 명령 하나로 DoD 7을 진행할 수 있다.
