# [다시 확인]이 지난 설치 결과를 지우게 (v0.1.4)

## 목표 / 하지 않을 것
- 목표: 준비물 띠의 [다시 확인]을 누르면 직전 [설치]의 항목별 결과와 오류 문구를 지우고 새로 확인한 준비물 상태만 보인다. v0.1.3 가상머신 테스트에서 개발자 도구 설치 후 [다시 확인]을 눌렀는데 「설치 중」 결과가 남아 아무 일도 없는 것처럼 보였던 문제. v0.1.4로 배포한다.
- 하지 않을 것:
  - forge 플러그인의 node 훅 경고 — forge(gyuha/forge) 쪽 문제라 이슈로 넘긴다(이 계획 밖).
  - [설치] 직후 자동 재확인의 동작 변경 — [설치]가 끝나면 결과는 계속 보여야 한다.

## 기준
- 용어: `.forge/CONTEXT.md`의 **준비물**
- 결정: 지우기는 [다시 확인] 버튼 전용 처리에서만 한다. `checkDeps`는 [설치] 직후에도 불리므로 거기서 지우면 설치 결과가 바로 사라진다.
