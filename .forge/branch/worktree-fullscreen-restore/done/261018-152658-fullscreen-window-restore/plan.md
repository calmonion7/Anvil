# 전체화면으로 종료해도 직전 일반 창 크기·위치로 다시 뜨게

## 목표
전체화면 상태에서 Anvil을 종료하고 다시 켜면, 전체화면에 들어가기 직전의 일반 창 크기·위치로 뜬다. 지금은 window-state 플러그인(`src-tauri/src/lib.rs:304`, FULLSCREEN 플래그만 제외)이 전체화면 순간의 화면 크기를 일반 창 크기로 저장해, 화면 크기의 일반 창으로 뜬다.

## 정해진 것 (fg-ask 2026-10-18)
- 전체화면 종료 → 직전 일반 크기·위치로 복원 (다시 전체화면으로 띄우지 않는다 — 기존 주석 "macOS 전체화면은 복원하지 않는다" 유지).
- 최대화 상태로 종료 → 지금처럼 최대화로 복원. 바꾸지 않는다.
- 판정: osascript 자동 판정 스크립트 + 사람 확인 한 번.

## 슬라이스
1. **S1 전체화면 중 저장 막기** — 전체화면일 때의 크기·위치가 저장 상태를 덮어쓰지 않게 한다(예: 종료 시 전체화면이면 저장 생략 / 전체화면 진입 전 값 유지). 방식은 실행 중 플러그인 동작을 확인해 고른다.
   - 완료: 아래 DoD 1·2 통과.
2. **S2 판정 스크립트** — `scripts/check-fullscreen-restore.sh`: 빌드한 앱 실행 → osascript로 창을 900×700 @ (100,100)으로 맞춤 → 전체화면 → 종료 → 재실행 → 창 크기·위치를 읽어 일치하면 통과. 이어서 최대화 케이스: 최대화 → 종료 → 재실행 → 최대화 상태(zoomed)로 뜨면 통과. 두 케이스 모두 통과해야 exit 0. 시작 전 `ioreg`의 `IOConsoleLocked`로 화면 잠금이면 "잠김"을 알리고 실패 처리(권한 탓으로 단정하지 않는다 — #5 회고).
   - 완료: 수정 전 코드에서 실패, 수정 후 통과.

## 완료 기준 (DoD)
1. `cargo test --manifest-path src-tauri/Cargo.toml` 통과 — 회귀 가드(지금도 통과해야 함).
2. `bash scripts/check-fullscreen-restore.sh` exit 0 — 전진 검사(전체화면 복원 + 최대화 회귀 두 케이스, fg-loop C2·C3). 사전 상태: 스크립트 없음(실패).
3. 사람 UAT: (a) 일반 창 크기를 바꾼 뒤 전체화면 → ⌘Q → 재실행 → 바꾼 일반 크기·위치로 뜬다. (b) 최대화 → ⌘Q → 재실행 → 최대화로 뜬다(회귀 없음).

## 하지 않는 것
- 전체화면 자체를 복원하는 것.
- 최대화 처리 변경.
- 다중 모니터 위치 보정.

## 참고
- 비로그인 셸에서 `tauri build`는 `~/.rustup/toolchains/stable-aarch64-apple-darwin/bin`을 PATH 앞에 붙인다(#5 회고).
- 워크트리에서 실행하면 이 백로그 파일은 브랜치 root로 **이동**한다(복사 금지 — #4·#5 회고에서 두 번 반복).
