## 계획과 달라진 점 · 그 자리 결정
- **채우기 방법**: `tmux send-keys -l`(글자만, Enter 없음). 대상 세션이 작업 중이면 서버 쪽에서도 한 번 더 막는다(화면 버튼이 꺼지기 전 찰나 대비).
- **세션이 없을 때**: 띄운 뒤 훅이 SessionStart(입력 대기)를 남길 때까지 최대 40초 기다리고, claude 화면이 입력을 받을 준비가 되도록 0.8초 더 쉰 뒤 채운다. 처음 여는 폴더라 claude의 폴더 신뢰 확인이 뜨면 기다림이 끝나지 않으니, 그 경우 "폴더 신뢰 확인을 먼저 해 주세요" 오류를 보인다.
- **막는 조건 문구**: 실행 세션이 작업 중이면 `#N 실행 중`(세션↔작업 연결이 있을 때) 또는 `실행 세션 작업 중`(연결 표지가 없을 때 — #2 (d)처럼 직접 실행 중일 수 있음). 계획 세션은 `계획 세션 작업 중`.
- **카드 구조**: 카드 전체가 버튼이라 안에 버튼을 넣을 수 없어, "문서 여는 영역 + 버튼 줄"로 나눴다(최근 완료 카드는 그대로 전체가 버튼).
- **숨긴 항목**: 열 머리에 `숨긴 항목 보기 (N)` 토글. 숨긴 항목을 펼치면 흐리게 보이고 '되돌리기' 버튼이 붙는다. 열 머리 개수는 숨긴 것을 뺀 수.
- **초점 이동**: 채운 뒤 그 세션 칸의 터미널에 초점을 준다. 세션을 새로 띄운 경우 터미널이 붙는 순간 초점을 준다.
