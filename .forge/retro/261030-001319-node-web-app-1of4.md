# 2026-10-30 — Node 전환 1/4: Tauri 백엔드를 Node 서버(node-pty·ws)로 옮기고 화면을 새 API로 연결

## 계획 대비 실제
- 계획대로 된 것:
  - S1 골든 → S2 서버·계약 → S3∥S4 → S5 → S6 순서. S2가 모듈 경계를 먼저 고정해서(`commands` export, `ctx.broadcast`, 모듈 소유 파일 지정) S3·S4가 같은 파일을 건드리지 않고 병렬로 끝났다.
  - Rust 출력을 JSON 골든으로 고정한 덕에 forge 읽기 이식이 "골든 초록"이라는 기계 판정 하나로 끝났다.
  - 사람 UAT 4항목이 한 번에 통과했다(재시도 0).
- 어긋난 것:
  - **DoD 1 명령이 실행 환경에서 그대로는 돌지 않았다.** `node --test server/`는 Node 22+에서 디렉터리를 모듈로 실행한다(24.15 실측). `server/` 가 없던 시점이라 그릴링 때 실측할 수 없었고, `server/index.js` 집계 진입점으로 메웠다.
  - **리뷰가 보안 결함 2건을 잡았다.** ① 개발 프록시가 위조 가능한 Host·Origin을 보고 서버 토큰을 붙여, 토큰 없이 터미널을 얻을 수 있었다(S5가 만들고 S6이 그대로 씀). ② 등록 저장소의 `.forge/*.md`를 `marked` → `{@html}`로 그려 그 안 스크립트가 돌았다 — Tauri 때부터 있던 결함이 웹 전환으로 터미널까지 닿게 됐다. CSP로 막았다.
  - **서버 재시작 뒤 401 무한 재접속**: "실행마다 새 토큰" 결정이 재접속 경로와 충돌했다. 401이면 멈추고 안내하게 했다.
  - 계획 밖: node-pty 1.1.0 prebuild의 `spawn-helper` 실행 권한 누락(`posix_spawnp failed`) → `server/pty.js`가 chmod. Chromium 한글 조합 입력 수정. 팝업 보드·창 기억은 `src/`에 없어 걷어 낼 것이 없었다(계획의 전제가 틀림).
  - UAT 중 한글 글자 간격이 벌어져 보였다. Chromium·WebKit 둘 다 같아 전환 전부터 있던 현상으로 보고 후속후보로 뺐다.
  - UAT용 백그라운드 서버가 메모리 부족 정리로 한 번 꺼졌다.

## 배운 점
- 다음엔 다르게:
  - **DoD에 새 디렉터리를 대상으로 한 명령을 적을 때는, 빈 임시 디렉터리로라도 그 명령 모양을 실측한다.** `node --test <dir>`처럼 런타임 버전에 따라 의미가 바뀌는 명령은 존재하지 않는 대상이라도 형식은 잴 수 있다. 2/4에서는 `package.json`의 `test` 스크립트로 DoD를 적는다.
  - **"터미널을 여는 로컬 서버"는 리뷰 단계를 생략하지 않는다.** 이번 major 3건 중 2건이 보안이었고, 하나는 이전부터 있던 것이었다. 2~4/4에서 설치 스크립트·자동 시작·업데이트를 붙일 때도 보안 렌즈 리뷰를 넣는다.
  - **인증 토큰 수명은 재시작·자동 시작·PWA와 함께 정한다.** "실행마다 새 토큰"은 서버 재시작 때 열린 탭을, 2/4의 로그인 자동 시작 뒤에는 PWA 창을 매번 깨뜨린다. 2/4 그릴링 첫 질문으로 둔다.
  - **화면 이식 계획을 쓸 때 "걷어 낼 화면 기능"은 `src/`에서 grep으로 위치를 확인하고 적는다.** 창 기억·팝업은 `src-tauri/`에만 있었다.
  - **병렬 조각은 앞 조각이 모듈 경계와 소유 파일을 정해 주게 한다**(이번에 잘 된 방식 — 유지).
  - UAT 서버는 백그라운드 셸이 메모리 압박에 정리될 수 있다. 사람 확인이 길어질 때는 사용자 터미널에서 띄우게 안내한다.
